# find-iv

AI-assisted search for instrumental variables (IVs) in empirical economics research.

一个帮助经济学实证研究者**寻找、筛查并论证工具变量（IV）**的 Codex skill，并扩展到寻找控制变量和断点回归（RDD）运行变量。

## 这是什么

`find-iv` 是一个可复用的 Codex skill。当你已经确定研究问题、处理变量（X）、结果变量（Y）和数据设定，需要设计因果识别策略时，它会引导一个 AI agent 陪你走完从"模糊题目"到"可写进论文的识别策略段落"的完整过程。

它的产出不是标准答案，而是一份**候选工具变量短名单**：每条候选都附**论证理由**和**潜在软肋**，最后由研究者本人做取舍。

## 为什么需要它

找工具变量是一个启发式、创造性的过程，而排他性（exclusion restriction）本质上无法用数据完全证明，只能靠"讲道理"来论证。传统的做法高度依赖研究者的经验和运气。本 skill 用**角色扮演 + 分步提示**的方式，让语言模型扮演真实经济主体去思考，而不是照抄学术文献里已有的 IV，从而更有可能产出新的候选。

## 核心设计

- **不直说"找 IV"**：全程用角色扮演，把问题翻译成"一个真实的人在真实场景里做决策"，避免模型直接背书文献。
- **分步推进**：先搜索（相关性 + 排他性），再细化（独立性），逐步收窄。
- **只给候选，不给裁决**：排他性无法完全验证，最终判断始终留给研究者。

## 工作流概览

0. 锁定研究卡片：确认 Y、X、因果问题、数据单位/时间/范围
1. 诊断内生性来源：遗漏变量 / 反向因果 / 测量误差 / 选择偏差
2. 拆解 X 的变化来源，分成外生与内生
3. 用角色扮演提示词生成候选工具变量
4. 文献借力 + 正交化，避免重复已有工具
5. 四项筛查：相关性、排他性、数据可得性、前例争议
6. 排他性对手审核，压力测试每个候选
7. 输出形式化检验清单
8. 输出可写进论文的识别策略段落与风险提示

## 安装

把整个 `find-iv` 文件夹放进 Codex 的 skills 目录（通常为 `$CODEX_HOME/skills`），使其结构为：

```text
$CODEX_HOME/skills/find-iv/SKILL.md
```

## 使用

在对话中通过 `$find-iv` 显式调用，或用自然语言描述需求（例如"帮我找工具变量"）触发。skill 会先向你确认研究设定，再按工作流逐步推进。

## 示例

研究问题：企业算力投入（X）如何影响其出口技术复杂度（Y）。

skill 会先确认研究设定、诊断内生性来源、拆解 X 的变化来源，再用角色扮演提示词生成候选工具，经过四项筛查和对手审核后，输出一份带理由和软肋的短名单，并整理成可写进论文的识别策略段落。
