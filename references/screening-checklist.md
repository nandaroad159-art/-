# 筛查与检验清单

## 候选工具四关筛查

对每个候选 Z 依次自问：

1. 相关性：Z 会不会确实推动 X？机制讲得通吗？
2. 排他性：有没有任何"Z 不经过 X、直接改变 Y"的路径？这是生死线。
3. 数据可得性：Z 的数据现在有吗，还是需要构造？
4. 前例与争议：这个 Z 是否已被用过，有没有已知批评？

## 形式化检验清单

- 第一阶段回归：Z 对 X 显著，F 统计量 > 10（弱工具检验）。
- 过度识别：多个 Z 时做 Hansen J / Sargan。
- 安慰剂检验：用"假工具"验证无效应。
- 平衡性 / 事件研究：DID 类做 pre-trend 平行趋势检验。
- 排他性间接论证：写成可辩护的文字论证。

## 必须遵守的警示

排他性不能用数据完全证明；检验通过 ≠ 工具一定干净。所有候选都要由研究者做最终判断。
